Telaah otomatis dengan AI tidak tersedia di halaman ini.
Fitur itu hanya aktif saat dibuka langsung di dalam chat Claude. Di sini (GitHub Pages / file lokal), semua fitur lain tetap gratis dan berfungsi penuh: pembacaan file di atas, penghitungan skor, cetak PDF, dan unduh Word.

Cara lanjut secara manual: buka "Lihat teks yang terbaca" di atas untuk membaca isi dokumen, lalu isi ke-22 butir penilaian di bawah berdasarkan teks tersebut.

Saat Anda menekan "Telaah Otomatis dengan AI", teks yang terbaca dari file akan dikirim ke Claude (API Anthropic) untuk dianalisis. Hasilnya adalah draf awal — periksa dan sesuaikan kembali sebelum digunakan sebagai hasil telaah resmi.

Semua fitur di halaman ini (baca file, hitung skor, cetak PDF, unduh Word) berjalan sepenuhnya di browser Anda, gratis, dan tidak mengirim data ke mana pun.
